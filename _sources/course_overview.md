# Course Overview

## Elective 4 – Deep Learning

This portfolio contains my laboratory tasks, activities, and assignments for **Elective 4 – Deep Learning**.

The purpose of this portfolio is to document my progress throughout the course and organize the practical work I complete while learning the foundations and applications of deep learning.

## What This Portfolio Contains

The portfolio currently includes laboratory tasks covering:

* Forward propagation in a neural network
* Error computation using a forward pass
* Backward propagation and gradient calculation
* Parameter and weight updates
* Linear regression using PyTorch
* Model training using MSE loss and SGD
* PyTorch tensor creation and manipulation
* Tensor reshaping, indexing, and matrix multiplication

As the course continues, additional activities, assignments, and laboratory tasks will be added to this portfolio.

## Laboratory Progression

### Laboratory Task 2 – Forward Pass and Error

This task performs a single forward pass through a **3-input, 2-hidden-unit, 1-output neural network** using the ReLU activation function. It includes the calculation of weighted sums, hidden activations, output prediction, and error.

### Laboratory Task 3 – Forward and Backward Propagation

This task builds on Laboratory Task 2 by performing a complete training step. It covers the forward pass, backward propagation, gradient calculation, parameter updates, and checking whether the update reduces the loss.

### Laboratory Task 4 – Linear Regression in PyTorch

This task introduces model training using PyTorch. A two-layer fully connected regression model is trained using the Diabetes dataset, MSE loss, SGD optimization, a batch size of 8, and 1000 training epochs.

### Laboratory Task 5 – PyTorch Tensor Basics

This task focuses on fundamental PyTorch tensor operations, including creating tensors, changing data types, reshaping, indexing, element-wise operations, and matrix multiplication.

This portfolio is intended to grow throughout the semester. New laboratory tasks, activities, assignments, and other course outputs will be added as they are completed.
