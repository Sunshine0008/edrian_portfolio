Computing the Unknown Shapes

The diagram leaves some shapes as ?. These are computed using the output size formula for convolution and pooling layers:

\[\text{Output Size} = \left\lfloor \frac{W - F + 2P}{S} \right\rfloor + 1\]

where $W$ is the input size, $F$ the kernel size, $P$ the padding, and $S$ the stride.

def calc_out(w, f, s, p):
    """
    Calculate output shape of a matrix after a convolution or pooling.
    The results are only applicable for square kernels and images only.
    """
    print(f'Output Shape: {(w - f + 2 * p) // s + 1}')

PyTorch Implementation

class QuickDrawCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=(3,3), stride=1, padding=1)
        self.pool1 = nn.MaxPool2d(kernel_size=(2,2), stride=2, padding=1)

        self.conv2 = nn.Conv2d(32, 64, kernel_size=(3,3), stride=1, padding=1)
        self.conv3 = nn.Conv2d(64, 128, kernel_size=(3,3), stride=1, padding=1)
        self.conv4 = nn.Conv2d(128, 256, kernel_size=(3,3), stride=1, padding=1)
        self.pool2 = nn.MaxPool2d(kernel_size=(2,2), stride=2, padding=0)

        self.dropout = nn.Dropout(p=0.2)

        self.fcn1 = nn.Linear(256*7*7, 1000)
        self.fcn2 = nn.Linear(1000, 500)
        self.fcn3 = nn.Linear(500, num_classes)

    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = self.pool1(x)

        x = F.relu(self.conv2(x))
        x = F.relu(self.conv3(x))
        x = F.relu(self.conv4(x))
        x = self.pool2(x)

        x = self.dropout(x)
        x = x.view(-1, 256*7*7)

        x = F.relu(self.fcn1(x))
        x = F.relu(self.fcn2(x))
        x = F.softmax(self.fcn3(x), dim=1)

        return x

Verifying the Layer Output Shapes

A dummy batch of 32 images of size (1, 28, 28) (the batch size in the diagram) is passed through the model. A forward hook prints the output shape of every layer so it can be compared with the diagram and the table above. 

def show_shape(name):
    def hook(module, inp, out):
        print(f"{name:8} -> {tuple(out.shape)}")
    return hook

for name, layer in model.named_children():
    layer.register_forward_hook(show_shape(name))

dummy = torch.randn(32, 1, 28, 28)
out = model(dummy)
print("output   ->", tuple(out.shape))

Discussion

The diagram was translated layer by layer into a torch.nn.Module. All convolution layers use a 3×3 kernel with stride 1 and padding 1, so they preserve the spatial size of their input while the number of channels increases from 1 to 32, 64, 128, and finally 256. The spatial size is reduced only by the pooling layers. MaxPool1 uses padding 1, which turns the 28×28 feature map into 15×15 instead of 14×14, and MaxPool2 (no padding) reduces it to 7×7. These values determine the input size of FCN1: the flattened feature map has 256 × 7 × 7 = 12544 values per image.

Dropout with p=0.2 is applied after the second pooling layer to reduce overfitting, and is active only in training mode. The fully connected part reduces the features to 1000, then 500, and the last layer outputs one value per class, converted to probabilities by softmax. Most of the parameters (about 12.5 million of the 13.4 million) are in FCN1, so the fully connected layers make up most of the model size, while the convolution layers, which extract the features, are comparatively small.
